# CrossPlatformLab-PulkitSharma

A Java-based cross-platform project demonstrating file-management functionality and automated multi-platform testing using GitHub Actions.

## Features

- Java-based file management functionality
- Cross-platform compatibility
- Automated GitHub Actions workflow
- Multi-operating-system testing
- Simple structure for learning CI/CD with Java

## Technologies

- Java
- Git
- GitHub
- GitHub Actions
- YAML

## Getting Started

### Requirements

- Java JDK installed
- Git installed

### Run the Project

Clone the repository:

git clone https://github.com/pk2447150-stack/CrossPlatformLab-PulkitSharma.git

Move into the project directory:

cd CrossPlatformLab-PulkitSharma

Compile:

javac FileManager.java

Run:

java FileManager

## CI/CD

This repository uses GitHub Actions to automatically test the project across multiple environments.

The workflow is located at:

.github/workflows/

GitHub Actions helps verify that the Java code works consistently across supported operating systems.
